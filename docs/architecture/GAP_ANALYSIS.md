## Cross-cutting distinctions

- V1 lifetime book P&L is `VirtualBook.pnl` and the `ExecutableStrategyLedger.snapshot` values since the initial mark.
- V1 recent executable movement is `ExecutableStrategyLedger.recent_changes`, consumed by `_derive_v1_books` as `RECENT_EXECUTABLE_BOOK_CHANGE`.
- V1 strategy/leg lifecycle is missing in the generic path and only partial/fixed in `TimedStraddlePosition` and `TimedStraddleRuntime.book.position`.
- V2 own position P&L is `PaperTradeManager` cash/position economics and `LongOptionRegimeExecutor._exit` summary, based on the V2 option entry and executable bid.
- V2 state-driven decisions are `StateDrivenPositionKeeper.observe` and `observe_quote`, which use continuing V1 evidence plus V2 bid-based P&L excursions.

## Specific missing controls

The current normal DeepLOB runtime subscribes one future and the selected CE/PE pair. `select_atm_reverse_iron_fly` proves that four contracts can be selected in a separate experiment, but it does not prove that historical quotes for those contracts exist or that the normal runtime subscribes them. Multi-strike strategies therefore require explicit subscription, persistence, freshness, and replay coverage before they can be accepted.
